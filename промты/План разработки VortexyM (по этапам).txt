План разработки VortexyM (по этапам)

Этап 0: Фундамент и окружение

Цель: настроить среду разработки, создать базу данных, базовые модели и систему аутентификации.

· Создать структуру проекта (backend, frontend) в Windsurf.
· Настроить Docker Compose для PostgreSQL и Redis.
· Инициализировать backend на Node.js/Express с Sequelize.
· Создать базовые модели: User, Session.
· Реализовать регистрацию с проверкой email и отправкой письма-подтверждения.
· Реализовать вход (логин) с выдачей JWT.
· Добавить middleware для проверки JWT.
· Настроить базовую защиту: хеширование паролей, переменные окружения, HTTPS (на сервере).

Этап 1: Пользователи и профили

Цель: реализовать все функции, связанные с пользовательским профилем, кроме стикеров и платных услуг.

· Добавить в модель User поля: birthYear, role, avatar, stickerLimit, invisible, invisibleExpiry.
· Реализовать редактирование профиля (имя, аватар, статус и т.д.).
· Реализовать публичный/приватный режим профиля.
· Реализовать чёрный список (модель BlockedUser).
· Реализовать кастомизацию профиля (темы, цветовые схемы) на клиенте.
· Добавить регистрацию с вопросами (год животного, математический пример) и блокировку на 24 часа (Redis).
· Внедрить защиту от брутфорса (лимит попыток входа через Redis).
· Реализовать базовую админку (простой просмотр пользователей) для тестирования.

Этап 2: Личные сообщения и реальное время

Цель: создать функционал личных сообщений с поддержкой реального времени и медиа.

· Настроить Socket.IO на сервере и клиенте.
· Создать модель Message (sender, receiver, text, type, fileUrl, status).
· Реализовать отправку/получение текстовых сообщений в реальном времени.
· Добавить голосовые сообщения (запись с микрофона, загрузка файла).
· Добавить видеосообщения (кружочки) (запись видео, загрузка).
· Добавить отправку файлов (изображения, документы).
· Реализовать умные функции:
  · Редактирование и удаление сообщений.
  · Ответы на конкретные сообщения (threads).
  · Реакции (лайки, эмодзи).
  · Закреплённые сообщения.
  · Пересылка сообщений.
· Добавить поиск по сообщениям (на стороне сервера).

Этап 3: Аудио/видеозвонки

Цель: внедрить звонки между пользователями и группами.

· Интегрировать SFU-решение (LiveKit или Jitsi).
· Реализовать сигнализацию для начала звонка через Socket.IO.
· Добавить личные звонки (аудио/видео).
· Добавить групповые звонки.
· Реализовать запись звонков (с уведомлением) и хранение записей.
· Обеспечить маскировку лица и искажение голоса для анонимных профилей (пока можно сделать заглушку, полная реализация позже).

Этап 4: Каналы

Цель: создать функционал публичных и закрытых каналов с постами и администрированием.

· Создать модели: Channel, ChannelMember, Post, Product, Poll, Event.
· Реализовать создание, редактирование, удаление канала.
· Добавить настройки приватности (публичный/закрытый) и ссылки-приглашения.
· Реализовать назначение администраторов с гибкими правами.
· Реализовать создание постов (текст, медиа).
· Реализовать массовую рассылку подписчикам.
· Добавить упоминания (@username, @all).
· Реализовать опросы и викторины.
· Добавить календарь событий.
· Реализовать блокировку пользователей в канале.
· Создать интеграцию с ботами (API для ботов).

Этап 5: Беседы (групповые чаты)

Цель: реализовать групповые чаты с ограничениями и расширением лимитов.

· Создать модель Conversation, ConversationMember.
· Реализовать создание, редактирование, удаление беседы.
· Установить лимит участников по умолчанию — 500.
· Добавить счётчик свободных мест.
· При достижении лимита показывать сообщение и ссылку «Увеличить лимит».
· Реализовать покупку пакетов расширения (+100 мест за 250 руб, +500 за 999 руб) — пока заглушка, интеграция с платежами позже.
· Реализовать функции для владельцев/админов (как в каналах).
· Ограничить обычных участников (только отправка сообщений, голосовых, кружочков).

Этап 6: Платежи и монетизация

Цель: подключить платёжную систему и реализовать все платные функции.

· Интегрировать платёжную систему (ЮKassa, Stripe) — создать модели Payment, Order.
· Реализовать покупку пакетов стикеров (разовые, навсегда).
· Реализовать покупку функции «Невидимка» (ежемесячная подписка).
· Реализовать покупку расширения лимита бесед (разовые пакеты).
· Добавить премиум-подписку (включает несколько функций).
· Реализовать покупку платных стикерпаков от проекта.
· Добавить платные темы оформления.
· Реализовать платные посты (pay-per-view).
· Внедрить реферальную программу (модель Referral, начисление бонусов).
· Настроить показ рекламы для бесплатных пользователей с возможностью отключения за плату.

Этап 7: Админ-панель (расширенная)

Цель: создать полноценную админ-панель для управления проектом.

· Создать отдельные маршруты для админки (например, /admin).
· Реализовать управление пользователями (блокировка, удаление, выдача галочки).
· Реализовать обработку заявок на верификацию (пользователи и каналы).
· Добавить систему жалоб (Complaint) и их модерацию.
· Реализовать логирование действий администраторов (модель AdminLog).
· Настроить резервное копирование (автоматический дамп БД и файлов).
· Реализовать управление рекламными блоками (создание, таргетинг).
· Добавить аналитику (графики активности, доходы).
· Реализовать объявления на площадке (текст, время показа).
· Реализовать настройку платежей (цены, тарифы).
· Реализовать функцию включения/выключения проекта.

Этап 8: Специальные профили и скрытые функции

Цель: реализовать профиль «Моргенштерн@» и создание анонимных страниц с маскировкой.

· Создать в БД профиль Моргенштерн@ с флагом hidden: true и указанными email/паролем.
· Обеспечить полную невидимость профиля (не показывать нигде, кроме как при прямом входе).
· Реализовать в этом профиле дополнительные пункты меню:
  · Изменение кодов блокировки/удаления.
  · Создание профиля без регистрации (обычного).
  · Создание анонимных (невидимых) страниц.
· Для анонимных страниц:
  · Создать флаг anonymous: true, hidden: true.
  · Установить неограниченные лимиты (стикеры, беседы).
  · Отображать имя как «Анонимный участник».
  · Скрыть аватар и всю информацию профиля.
  · При отправке видеосообщений применять размытие лица и искажение голоса (интеграция с FFmpeg или клиентскими библиотеками).
· Реализовать функцию полной блокировки площадки через профиль Моргенштерн@ (по коду).
· Реализовать функцию полного удаления проекта (таймер, архивация, отправка на email, самоуничтожение).

Этап 9: Локализация, PWA и финальные улучшения

Цель: сделать проект готовым к международному использованию и улучшить пользовательский опыт.

· Настроить i18n на клиенте (файлы переводов для 5 языков).
· Добавить переключатель языков.
· Реализовать PWA (манифест, service worker для офлайн-доступа).
· Добавить горячие клавиши.
· Добавить папки для чатов (сортировка).
· Провести нагрузочное тестирование (JMeter) и оптимизировать узкие места.
· Финальное тестирование всех функций, включая безопасность (пентест).
· Подготовить документацию (пользовательскую и техническую).
· Развернуть проект на боевом сервере.

---

Как использовать этот план в Windsurf

1. Создайте в корне проекта папку plans.
2. Внутри создайте файлы: 00-foundation.md, 01-users.md, 02-messages.md и так далее, соответствующие этапам.
3. В каждом файле подробно опишите подзадачи, как указано выше. Можно копировать пункты и дополнять.
4. В процессе разработки открывайте нужный файл и просите Cascade помочь с реализацией конкретной подзадачи, ссылаясь на файл плана.

Такой подход обеспечит чёткое видение проекта и позволит ИИ всегда понимать контекст. Удачи в создании VortexyM!
