Полное техническое задание для создания веб-мессенджера VortexyM (финальная версия с дополнениями)

Цель: разработать полноценный веб-проект — мессенджер с названием VortexyM, реализующий все описанные ниже функции. Проект должен включать клиентскую и серверную части, базу данных, поддержку реального времени (WebSockets), аудио/видеозвонки (WebRTC), интеграцию с платёжной системой и механизмы безопасности.

---

1. Общие требования

1.1. Архитектура

· Желательно использование микросервисной архитектуры (отдельные сервисы для чатов, звонков, платежей, файлов, админ-панели) для упрощения масштабирования и повышения отказоустойчивости.

1.2. Аудио/видеозвонки

· Реализовать через WebRTC с сигнальным сервером (Socket.IO). Для групповых звонков использовать готовые SFU-решения, например LiveKit, Jitsi или Mediasoup, вместо написания собственного SFU с нуля.
· Добавить функцию записи звонков (с обязательным уведомлением участников) и хранения записей в облаке.

1.3. Хранение и оптимизация файлов

· Использовать CDN для раздачи статического контента (аватары, стикеры, медиафайлы).
· Для видео (особенно «кружочков») применять транскодирование в разные битрейты для адаптивной загрузки.

1.4. Кэширование и очереди

· Применять Redis для кэширования сессий, счетчиков, статусов онлайн.
· Для обработки фоновых задач (массовые рассылки, уведомления, архивация) использовать очереди сообщений, например RabbitMQ или Kafka.

1.5. Локализация (i18n)

· Интерфейс должен поддерживать переключение между языками: русский (по умолчанию), английский, французский, татарский, таджикский.
· Использовать стандартные библиотеки локализации (например, i18next для React/Vue). Все тексты интерфейса, системные уведомления, ошибки, подсказки, а также контент, генерируемый площадкой (объявления админов), должны быть переведены.
· Предусмотреть возможность добавления новых языков через админ-панель без изменения кода.

2. Пользовательские функции (для всех зарегистрированных пользователей)

2.1. Регистрация и вход

· Регистрация по email с подтверждением (письмо с ссылкой).
· Два дополнительных вопроса при регистрации:
  1. «В год какого животного вы родились?» — выпадающий список годов, правильный ответ зависит от выбранного года.
  2. Математический пример (например, «2+2*2»). Ответ вычисляется на сервере.
· При неверном ответе на любой вопрос — блокировка IP и email на 24 часа.
· Защита от брутфорса: ограничение количества попыток входа (например, 5 неудачных попыток за 15 минут — временная блокировка).

2.2. Профиль пользователя

· Полное редактирование: имя, фамилия, никнейм, аватар, дата рождения, статус, контактные данные.
· Публичный/приватный режим.
· Чёрный список (блокировка пользователей).
· Кастомизация профиля: тема оформления, цветовая схема.
· Стикеры:
  · Бесплатный лимит: 5 собственных стикеров.
  · Разовые покупки дополнительных мест навсегда:
    · 5 мест — 100 руб.
    · 10 мест — 150 руб.
    · 20 мест — 350 руб.
· Истории — временные посты (фото/видео), исчезающие через 24 часа (как в Instagram/Telegram). Возможность просмотра историй подписчиков.
· Статусы — текстовые или эмодзи, отображаемые рядом с именем.
· Рейтинг/уровни за активность (для геймификации).
· QR-код профиля для быстрого добавления в контакты.

2.3. Функция «Невидимка»

· Платная функция: 15 рублей в месяц.
· Скрывает онлайн-статус и время последнего посещения.

2.4. Получение подтверждения (галочки) для пользователя

· Заявка с ФИО, фото паспорта, описанием причины.
· Рассмотрение в админ-панели.

2.5. Функции для конфиденциальности

· Секретные чаты (end-to-end шифрование) для особо важных переписок.
· Автоматическое удаление сообщений через заданное время (таймер).
· Предупреждение о скриншотах (технически сложно, но можно показывать уведомление, что собеседник сделал скриншот, или блокировать скриншоты в некоторых чатах программно).

3. Личные сообщения (диалоги)

· Стандартные функции: текст, голосовые, видеосообщения (кружочки), файлы.
· Умные функции:
  · Редактирование и удаление отправленных сообщений (с историей правок для администраторов).
  · Ответы на конкретные сообщения (threads).
  · Реакции (лайки, эмодзи) на сообщения.
  · Закреплённые сообщения в диалоге.
  · Пересылка сообщений с возможностью добавить комментарий.

4.1. Создание и управление каналом

· Владелец и администраторы (с настраиваемыми правами).
· Функции: редактирование канала, посты, монетизация, товары, видеосообщения, удаление постов, блокировка пользователей, передача прав, удаление канала, массовая рассылка, упоминания, скрытие администрации.

  · Интеграция с ботами — открытый API для создания сторонних ботов (погода, новости, игры).

4.2. Получение подтверждения (галочки) для канала

· Только для открытых каналов: заявка с документами компании и описанием.

5.2. Функции для владельца и администраторов беседы

5.3. Функции для обычных участников беседы

· Отправка сообщений, голосовых, видеосообщений.

· Логирование действий администраторов (см. п.6).
