Цель: создать полноценную админ-панель для управления проектом.

· Создать отдельные маршруты для админки (например, /admin).
· Реализовать управление пользователями (блокировка, удаление, выдача галочки).
· Реализовать обработку заявок на верификацию (пользователи и каналы).
· Добавить систему жалоб (Complaint) и их модерацию.
· Реализовать логирование действий администраторов (модель AdminLog).
· Настроить резервное копирование (автоматический дамп БД и файлов).
· Реализовать управление рекламными блоками (создание, таргетинг).
· Добавить аналитику (графики активности, доходы).
· Реализовать объявления на площадке (текст, время показа).
· Реализовать настройку платежей (цены, тарифы).
· Реализовать функцию включения/выключения проекта.

· Просмотр информации о VPN-подключениях:
  · В админ-панели добавить в карточку пользователя отображение IP-адресов, с которых он подключался (история), с пометкой, использовался ли прокси (на основе наличия заголовков X-Forwarded-For или если IP принадлежит известным VPN-диапазонам – опционально).
  · Добавить фильтр по пользователям, использующим прокси (для аналитики, но не для блокировки).
· Настройки блокировок:
  · В разделе настроек площадки добавить возможность администраторам отключать автоматическую блокировку по IP (или настраивать её чувствительность) для случаев, когда VPN-пользователи могут массово попадать под ограничения.
  · Предусмотреть возможность ручной разблокировки по комбинации email+IP.
· Логирование:
  · В логах администраторов фиксировать реальный IP (с учётом прокси) для прозрачности.
